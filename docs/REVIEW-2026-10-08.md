## Bugs fixed

1. **The `__expr:` hatch leaked from SET into the no-PK WHERE clause**
   (`dml.lua`, commit `25433ca`). The primary-key WHERE path kept the
   hatch closed (explicit `nil`), but the all-columns fallback forwarded
   the caller's `allow_expr` — so on a table without a primary key, a
   STORED text value that merely starts with `__expr:` went into the
   WHERE as raw SQL. The destructive shape: a cell holding
   `__expr:1=1 OR 1=1` made the WHERE true for every row, and one
   unrelated cell edit rewrote the whole table. WHERE values are data,
   never input typed this commit — the fallback gates like the pk path.
   Pinned by an editor-path no-PK spec (the existing spec only pinned
   the hatch-closed caller).

2. **Line-1 anchors went blind on a leading UTF-8 BOM**
   (`constants.lua`, commit `fd25d8f`). A BOM-writing editor glues
   U+FEFF to the first line, where it is not `%s`: the anchored
   directive matcher, the directive-comment skip in statement
   extraction and the `###` section marker all failed exactly when they
   sat on line 1 — the file's `-- @connection` went unseen and exec-file
   reported the connection "not found" (the Rust
   `extract_connection_directive` had the same hole, fixed in poste.nvim
   the same day). `strip_leading_bom` runs before all three matches.
   Pinned by the BOM spec, including the mid-line non-match.

3. **The browser table-ops keymaps answered to the wrong names**
   (`table_ops.lua` + `config.lua` + `help.lua`, commit `060975e`).
   `register_keymaps` read a browser keymap group's action names
   (select_all/refresh_all/describe_all/toggle_menu) while the four
   keys actually prompt for add/rename/drop/alter-column DDL:
   `:PosteDbHelp` described `ma` as "SELECT * from table", and a config
   that disabled `select_all` silently lost add-column. The section now
   names the four real actions; a pre-rename override (or `false`) of
   the legacy names still wins, read before the new ones. Pinned by
   four specs (defaults, legacy override, legacy disable, help copy).

## Probed, held (recorded on purpose)

- `string.format("%d", port)` with a non-integral TOML float
  (`port = 5432.5`, legal TOML) reaching `format_connection`: measured
  on this Neovim build — LuaJIT accepts the float and truncates, so the
  picker does NOT crash (the comment above the line only covers the
  string case it was written for). Held with an eye on any future Lua
  runtime bump: under Lua 5.4 semantics the same line raises.
- `toggle_pagination` does not block on a dirty edit state, unlike every
  other page flip: the flip only re-renders, `edit_state` survives it,
  and blocking would make the toggle unusable mid-edit. Intentional.
- `dml.generate_insert` skips a literal `"[Auto]"` string — the
  cell-editor marker for "let the default apply". A row whose real data
  is the text `[Auto]` cannot be inserted literally; the marker has been
  the contract since the editor shipped.
- `page.refresh_page` computes the page size off the (clamped) page:
  `apply_page_bounds` clamps a stale `tab.page` before the arithmetic,
  so a shrinking row set cannot drive `page_rows` negative.
