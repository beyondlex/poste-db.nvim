## Fixes (each with tests)

- **`connections.build_conn_url` crashed on a non-string field.** The
  TOML parser turns `host = [1]` into a real table; `url_host` then died
  on `:sub`, `percent_encode`'s caller on `..`, and the sqlite branch on
  `:find` — and completion, the winbar and the db browser all resolve on
  every redraw, so one typo took them all down. Every field the builder
  concatenates (`url`, `host`, `path`, `user`, `password`, `database`)
  is now type-gated up front with an error naming the connection and the
  field. The redis sibling's round-24 fix for its own builder, mirrored.
- **`session_conn.on_exit` sat behind `vim.schedule`** — left over from
  the original commit, before the family learned (redis sibling,
  AGENTS.md pitfall) that job callbacks already run on the main loop and
  a schedule added mid-`vim.wait` is not pumped in headless runs. A dead
  session's pending requests could stay parked past any wait that should
  have seen them fail. Called directly now; a spec fires `on_exit` by
  hand and pins the synchronous failure + pool cleanup.
- **`dataset.format_wallclock`** raised inside `os.date` on a non-numeric
  sec; the history render must not be killable by one malformed
  timestamp (`tonumber` + `os.time()` fallback — the same stroke as the
  redis sidebar's `build`).
- **`dataset.apply_page_bounds`** divided by `tab.page_size` unchecked;
  a hand-built tab (tests, a future caller) degraded the render into a
  crash instead of single-page math. Falls back to 1.
- **`editor/cell` type classifiers** indexed `ctype:lower()` on any
  input; nil from broken metadata or a number from a weird driver now
  classifies `false` — the answer `is_json_column`'s guard already
  gives — instead of crashing the caller that asked "is this editable?".
- **`ai/mentions.match(nil)`** indexed `token:match` (the generic chat's
  completion must fall back to file mentions, not break); `resolve(nil)`
  crashed on `ref.connection` before its own malformed-mention error
  path could fire. Both guard on type and route to the nil/error return.

## Read, not changed (recorded on purpose)

- **`nav_sort.build_sort_render_payload` trusts `tab.layout` to exist**
  (its comment says render_dataset guarantees it) — a probe with a
  hand-made tab reached `render_view` and died there. Every real caller
  comes through render_dataset, so this stays a contract, not a guard;
  revisit if a second tab-builder appears.
- **No stall watchdog on the SQL session pool** (the redis pool has one
  at 10s). Deliberate: SQL statements legitimately run for minutes, so
  the redis stroke would kill healthy long queries; a wedged-but-live
  TCP connection surfaces through the driver's own error eventually.
  Revisit only with a much larger, config-scaled limit.
