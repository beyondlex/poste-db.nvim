## Fixes (each with tests)

- **The DML guard's regex fallback now scans BOTH quote-escape
  readings** (`dml_guard.lua`). `strip_non_code` consumed backslash
  escapes in every quote style, but the dialects disagree about `\'` —
  MySQL's default reads it as an escaped quote, PostgreSQL/SQLite
  (`standard_conforming_strings` on) close the literal there. Either
  single reading can park an unfiltered DELETE inside a phantom
  literal: the backslash reading swallows the `;`-separated DELETE that
  follows a postgres-legal `'a\'; DELETE FROM users`, the standard
  reading hides a MySQL-legal `'it\'s'; DELETE FROM t`. tree-sitter
  covers the first case when the parser is installed, but regex_scan is
  the ONLY engine when it is not — and a confirm gate must over-flag,
  never under. `strip_non_code` takes the reading as a parameter
  (default unchanged) and `regex_scan` unions both, deduped on
  kind+snippet so one risky statement still asks once.
- **The export identity chain is type-gated** (`export.lua`). A
  numeric `table_name` on a hand-built tab reached `:gsub` on a number
  and killed the whole export with a Lua error instead of a notice.
  `str()` now passes strings, renders numbers/booleans as text, counts
  everything else absent so the `or` fallback chain (meta, layout,
  dialect default) gets its turn — and `generate_filename` applies the
  same gate itself, since it is also a `_test` entry point a future
  caller can reach directly.
- **`tunnel.normalize_cfg` type-gates `key` and `port`**
  (`tunnel.lua`). The TOML parser turns `key = [1]` into a real table;
  reaching `build_ssh_cmd` it landed in the ssh argv — a spawn-time
  failure on the resolve path that completion and the winbar walk on
  every redraw. A non-string key now errors with the field named (same
  shape as round 47's `build_conn_url` gate); a non-numeric,
  non-string port errors instead of silently becoming 22.
- **`statusline.get_ctx_color` type-gates `color`/`link`/`bg`**
  (`statusline.lua`). `color = [1]` in connections.toml reached `:sub`
  inside a function every statusline redraw runs — the redis sibling
  closed the same hole in its own copy this round (dd5ebd3), and the
  two implementations had drifted exactly the way the family's mirrors
  do. A non-string field counts as absent; the entry renders uncolored.

## Change (with tests)

- **The statement map passes the buffer's dialect to the binary**
  (`statement.lua`, `sql_runner.lua`). `context stmt` /
  `stmt-ranges` accept `--dialect` now (poste.nvim 281ee3d): the span
  that decides what "run statement under cursor" executes reads string
  literals the way `exec-file` splits the same buffer, so a MySQL
  `'it\'s'` no longer puts the two paths' boundaries in different
  places. `source_format.resolve_dialect` (### header, connection
  config, filetype) resolves once per run; the cursor path resolves
  lazily so the tree-sitter path, the common case, never pays for it.
  The flag is omitted when nothing resolves — today's standard reading.

## Probed, held

- `ident.quote` / `quote_ref` on hostile names (empty, `*`, `my..table`,
  trailing dots): the documented split/refuse contract holds.
- `import/mapping.coerce_value` on non-string raw cells, empty strings,
  `007` in a varchar column, out-of-double-range integers: all degrade
  to the documented nil/NIL/string shapes.
- `ai/mentions.table_line` always returns a string (never nil), which
  is what `ai/schema.lua`'s shrink loop pesc's — no nil reaches it.
- `ai/schema.render`'s MAX_CHARS shrink loop: `vim.pesc` pattern plus
  `%%`-escaped replacement survive comments/brackets in column lines.

## Read, not changed (recorded on purpose)

- **`statusline.get_ctx_color` has no fingerprint cache** — the redis
  sibling memoizes per `(color,link,bg)` and drops on ColorScheme; this
  copy re-runs `hlexists`/`nvim_get_hl` on every redraw. Functional,
  just a perf nicety; revisit if redraw profiling ever points here.
- **`dml_guard`'s tree-sitter path and the regex fallback can flag
  different statements for the same text** (different escape readings,
  different parsers). The union direction this round only applies to
  the fallback; the TS path is at least as conservative for the shapes
  probed. If a bypass is ever reported with TS installed, start there.
