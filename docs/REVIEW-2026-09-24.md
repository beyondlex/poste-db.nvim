## Recorded, not changed (with rationale)

- **`toml.lua` rejects a quoted key that contains a dot**
  (`"my.key" = 1` errors as a dotted key, because the dotted-key check
  looks at the raw key text). TOML-legal shape, but no `connections.toml`
  in the family uses a quoted dotted key, and the file is the vendor
  SOURCE of poste-redis's copy — a fix belongs here first, then a re-copy
  with the bumped commit pin, plus tests on both sides. Deliberately not a
  one-sided patch.
- **`extract_stmt_at_cursor`'s Lua `;`-heuristic fallback** stops its
  backward scan at any line containing `;` — one inside a multi-line
  string misplaces the statement start. It runs only when BOTH
  tree-sitter and the binary's `context stmt` are unavailable (the
  installed-binary path is the norm), and the heuristic's approximation is
  its documented contract.
